Yandex Photo Backup

Личное приложение для резервного копирования файлов из Яндекс Диска в Google Диск.

Владелец подключает свои облачные аккаунты и запускает rclone на своём сервере. Приложение предназначено для его личного использования.

Как используются данные

Как устроено копирование

rclone читает каталог Яндекс Диска, сравнивает файлы с резервной копией и передаёт доступные файлы в отдельную папку Google Диска. Данные проходят через сервер владельца; хранение полной промежуточной копии на сервере не требуется.

Повторные запуски проверяют сохранённое и снова пробуют скопировать недоступные ранее файлы. Используется команда copy: исчезновение файла из источника само по себе не удаляет сохранённую копию.

Зачем нужен доступ Google

Доступ через Google OAuth позволяет rclone создавать папку резервной копии, загружать файлы и читать необходимые сведения о файлах для сравнения. Фактические разрешения показаны Google перед подтверждением доступа.

Где можно отключить доступ?

Владелец может отозвать разрешение в подключениях своего аккаунта Google. Последующие операции с этим доступом перестанут работать; уже сохранённые файлы остаются под управлением владельца.

О приложении

Настройку поддерживает владелец аккаунта xDingoGG. Приложение использует rclone и не является официальным продуктом Яндекса или Google.

Политика конфиденциальности объясняет работу с данными. Условия использования описывают назначение и ограничения приложения.
